# 项目状态与续接文档

> 更新时间：2026-09-07。下次会话从本文档恢复上下文。

## 项目目标

将一整套信息技术类培训课程（视频 10–30 分钟/个）系统性重做：AI 学习理解 → 知识核验 → 按课程大纲逐集改编 → 用 AI 工具重新制作视频（HTML 母版 + MP4 + 音频），产出知识密度高、准确、结构清晰的新课程。

## 核心决策记录

1. **三层架构（2026-09-07 定稿）**：项目不是逐个视频孤立改编，而是：
   - 第0层 课程级：编目 → 批量粗理解（Whisper转写+快扫摘要）→ 课程知识图谱（概念归一/依赖/覆盖/顺序分析）→ 教学大纲 → 🔒人工定稿（全项目最重要审核）
   - 第1层 模块级：每模块定改编策略（重做/合并/拆分/新补充/保留）
   - 第2层 视频级：五阶段管线（拆解→多模态理解→事实核验→脚本重组→视频制作），脚本必须对齐大纲，术语全局统一
2. **先做第0层教学大纲，再逐集改编**。深度多模态理解只用于被选中改编的视频；大纲阶段用低成本快扫。
3. **技术要点**：时间戳全程溯源；代码识别三层兜底（多帧OCR投票+LLM语法修复+沙箱执行）；核验三级报告（🔴错误/🟡过时/🟠缺失）；两道人工闸门（A:理解+核验之后，B:脚本之后，加上第0层的大纲定稿共三道）；音画同步用"音频实测时长驱动时间轴"；Playwright逐帧渲染+FFmpeg合成。
4. **迭代策略**：先选1个10分钟典型视频跑端到端MVP；之后分赛道优化（概念型/代码走查型/操作演示型）；每集更新错误账本。
