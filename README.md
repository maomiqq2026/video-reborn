# 培训视频 AI 重做项目

将信息技术类培训视频（10–30 分钟/个）经 AI 理解、核验、重组后，重新制作为知识密度更高、更准确、结构更清晰的新培训视频（HTML 母版 + MP4 渲染 + 音频）。

## 流水线（五阶段 + 两道人工审核闸门）

```
原视频 → ① 素材拆解 → ② 多模态理解 → ③ 事实核验
       → 🔒闸门A(人工) → ④ 脚本重组 → 🔒闸门B(人工) → ⑤ 视频制作 → 交付
```

- 每阶段产物为结构化中间文件（JSON/Markdown），可定位、回滚、局部重跑
- 时间戳全程可溯源：原视频每一秒 ↔ 新脚本每一场景

## 目录结构

| 目录 | 用途 |
|---|---|
| `pipeline/` | 各阶段自动化脚本（Python） |
| `videos/raw/` | 原始视频输入（不入库） |
| `workspace/<video_id>/` | 单视频的中间产物与成品（chunks/、understanding.json、verification_report.md、script.json、output/） |
| `templates/` | HTML 场景模板、设计系统 |
| `reviews/` | 人工审核记录（闸门A/B） |
| `docs/` | 方案文档、错误账本 |

## 阶段说明

1. **素材拆解**：FFmpeg 双轨抽帧（定时+场景切换检测）、Whisper 词级时间戳转写、按语义边界切 2–4 分钟 chunk
2. **多模态理解**：提取知识点/代码/操作步骤/关键画面；代码用多帧 OCR 投票 + LLM 语法修复 + 沙箱执行三层兜底；全片完成后做跨 chunk 推理（实体消解、前向引用补全、遗留悬念检测）
3. **事实核验**：技术核验（API/代码真实性）+ 时效核验（版本过时）+ 一致性核验（前后矛盾），产出 🔴错误/🟡过时/🟠缺失 三级报告
4. **脚本重组**：大纲先行、教学重构（删冗余、补前置、先结论后展开），脚本含 source_refs 溯源
5. **视频制作**：HTML 母版 → TTS 逐句生成（音频时长驱动时间轴）→ Playwright 逐帧渲染 + FFmpeg 合成；交付 MP4 + HTML 交互版 + 讲义 + 核验报告

## 开发约定

- 先用 1 个 10 分钟典型视频跑通端到端 MVP，再分赛道优化（概念型/代码走查型/操作演示型）
- 每集完成后更新 `docs/error_ledger.md`（错误账本），反哺 prompt 与流程
